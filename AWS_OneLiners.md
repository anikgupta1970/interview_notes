| **Service**           | **Interview One-Liner (How to Mention It)**                                                         |
| --------------------- | --------------------------------------------------------------------------------------------------- |
| **EC2**               | Used EC2 to host applications where we needed full control over OS, networking, and runtime.        |
| **Lambda**            | Used AWS Lambda for event-driven backend logic to avoid server management and scale automatically.  |
| **Fargate**           | Used AWS Fargate to run containerized microservices without managing EC2 instances.                 |
| **ECS**               | Used Amazon ECS to orchestrate Docker containers and manage microservices deployments.              |
| **EKS**               | Used Amazon EKS to run Kubernetes workloads without managing the control plane.                     |
| **Elastic Beanstalk** | Used Elastic Beanstalk to deploy applications quickly without worrying about infrastructure setup.  |
| **App Runner**        | Used AWS App Runner to deploy web APIs directly from source code with minimal configuration.        |
| **S3**                | Used Amazon S3 for storing application assets, logs, and backups with high durability.              |
| **EBS**               | Used Amazon EBS for persistent block storage attached to EC2 instances.                             |
| **DynamoDB**          | Used DynamoDB for highly scalable, low-latency data like user sessions and metadata.                |
| **RDS**               | Used Amazon RDS to manage relational databases with automated backups and patching.                 |
| **Aurora**            | Used Amazon Aurora for high-performance MySQL/PostgreSQL workloads with better scalability.         |
| **Aurora Serverless** | Used Aurora Serverless to automatically scale database capacity based on application traffic.       |
| **VPC**               | Used Amazon VPC to isolate application resources and control network access securely.               |
| **ALB**               | Used Application Load Balancer to route HTTP traffic across services and enable path-based routing. |
| **NLB**               | Used Network Load Balancer for high-performance TCP traffic with low latency.                       |
| **API Gateway**       | Used API Gateway to expose REST APIs securely and integrate them with Lambda services.              |
| **Route 53**          | Used Route 53 for DNS management and routing traffic to AWS resources.                              |
| **SQS**               | Used Amazon SQS to decouple services and handle asynchronous processing reliably.                   |
| **SNS**               | Used Amazon SNS for sending notifications and fan-out messaging to multiple subscribers.            |
| **EventBridge**       | Used EventBridge to build an event-driven architecture and route events between services.           |
| **IAM**               | Used IAM roles and policies to manage secure access between AWS services.                           |
| **Cognito**           | Used Amazon Cognito for user authentication and JWT-based authorization.                            |
| **KMS**               | Used AWS KMS to encrypt sensitive data and manage encryption keys securely.                         |
| **CloudWatch**        | Used CloudWatch for application monitoring, logging, and setting up alarms.                         |
| **CloudTrail**        | Used CloudTrail to audit AWS API calls for security and compliance tracking.                        |
| **CodePipeline**      | Used CodePipeline to automate CI/CD workflows from code commit to deployment.                       |
| **CodeBuild**         | Used CodeBuild to compile, test, and package applications during CI.                                |
| **CodeDeploy**        | Used CodeDeploy for automated and zero-downtime application deployments.                            |
| **Athena**            | Used Athena to run ad-hoc SQL queries directly on data stored in S3.                                |
| **Glue**              | Used AWS Glue for serverless ETL jobs to transform and prepare data for analytics.                  |
